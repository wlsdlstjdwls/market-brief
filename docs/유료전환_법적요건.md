# 유료 전환 법적 요건

작성 2026-09-15. 코드 변경 없음, 조사 문서다.

**전제 — 종목을 넣지 않는 한 유사투자자문업 신고는 해당 없다.** 지수·금리·환율·유가·수급·업종
강약만 다루고 개별 종목의 매매 판단을 제시하지 않으면 "투자자문"에 해당하지 않는다는 게
이 프로젝트의 설계 전제다(`CLAUDE.md` 절대 규칙 1). 유료화하면서 종목을 넣는 순간 전제가 깨지고
자본시장법상 유사투자자문업 신고 대상이 된다. 조문 번호는 **확인 필요**(금융위 신고 창구 기준으로
재확인할 것). 요건이 아니라 **금지선**으로 관리한다.

아래 금액·수치는 법 개정으로 바뀌므로, 실제 신고 직전에 법제처 국가법령정보센터에서 재확인한다.
확신이 없는 항목은 "확인 필요"로 남겨 뒀다. 추정해서 적지 않았다.

## 1. 사업자등록

| 항목 | 내용 |
|---|---|
| 근거 | 부가가치세법 제8조(사업자등록) |
| 시기 | 사업 개시일부터 20일 이내 |
| 미이행 제재 | 미등록 가산세(공급가액 기준) + 등록 전 매입세액 불공제. 가산세율은 **확인 필요** |
| 조치 | 홈택스 온라인 신청. 업종코드는 "정보서비스업 / 온라인 콘텐츠 구독" 계열로 상담 후 결정(코드 번호 **확인 필요**). 개인사업자로 시작해도 무방 |

부수 효과: 과세사업자가 되면 구독료에 부가세 10%가 붙는다. **가격을 정할 때 세전·세후를 먼저 정해야 한다.**

## 5. 정기결제 해지·환불 고지

| 항목 | 내용 |
|---|---|
| 근거 | 전자상거래법 제17조(청약철회 등) 및 제18조(청약철회 등의 효과). 디지털콘텐츠의 청약철회 제한 사유는 **확인 필요**(제17조 제2항 각 호) |
| 조치 | ① 청약철회 기간·방법·환불 절차를 가입 화면에서 고지 ② **해지를 가입만큼 쉬운 경로로** 제공(마이페이지에서 즉시 해지) ③ 정기결제는 결제 예정일 전 사전 고지 ④ 이미 이용한 기간에 대한 정산 기준을 약관에 명시 |
| 미이행 제재 | 시정조치·과태료, 환불 분쟁 시 사업자 불리 |

디지털콘텐츠는 "제공이 개시되면 철회 제한"이 가능하지만, 그 제한을 쓰려면 **철회가 제한된다는 사실을
사전에 고지하고 동의를 받아야** 한다. 고지 없이 제한하면 제한 자체가 무효다.

## 6. 광고성 정보 전송 (메일 발송에 직결)

| 항목 | 내용 |
|---|---|
| 근거 | 정보통신망 이용촉진 및 정보보호 등에 관한 법률 제50조(영리목적의 광고성 정보 전송 제한) |
| 조치 | ① **사전 수신동의**(옵트인) ② 제목 맨 앞에 `(광고)` 표시 — 광고성 정보일 때 ③ 본문에 전송자 연락처와 **수신거부 방법**을 명시 ④ 수신거부는 무료·간편하게 ⑤ 동의 후 2년마다 수신동의 여부 재확인 ⑥ 야간(21시~익일 08시) 광고 전송은 별도 동의 필요 |
| 미이행 제재 | 과태료. 금액 **확인 필요** |

**지금 구현과의 접점**: `subscriber.status`가 `pending`에서 시작하고 `confirmToken`·`confirmedAt`이 있는 건
더블 옵트인(확인 메일 클릭 → `confirmed`)을 전제로 한 구조다. 확인 메일을 붙이기 전까지는
접수만 쌓이고 발송하지 않는다. 브리핑 본문이 순수 정보성이면 `(광고)` 표시 대상이 아닐 수 있으나,
유료 상품을 권유하는 문구가 한 줄이라도 섞이면 광고성으로 본다. **유료 전환 후 뉴스레터에
프로모션을 섞을 거면 처음부터 광고성으로 취급하는 편이 안전하다.**

1. 사업자등록 → 2. 구매안전서비스 확인증 발급 → 3. 통신판매업 신고 → 4. 처리방침·이용약관 작성·게시
→ 5. 푸터 표시 항목 추가 → 6. PG 계약·결제 연동 → 7. 해지·환불 화면 → 8. 메일 더블 옵트인·수신거부 링크

1~3은 코드와 무관하고, 4~8이 이 저장소의 작업이다.
